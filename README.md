# NuinuiMods
A mod loader for the game FLARE NUINUI QUEST

## Installation

- Download the latest release from [the releases page](https://github.com/StellatedCUBE/NuinuiMods/releases) for your platform. (`exe` for Windows, `x64` for Linux)
- Place it in the same folder as FLARE NUINUI QUEST. (Use “Browse Game Files” on Steam to find the correct folder for that version.)
- Run it. The first time you do so, there may be a longer launch while the game files are extracted.

## Installing Mods

Mods are distributed as `asar` files.
There should be a folder in your FLARE NUINUI QUEST folder called `NuinuiMods`. Place your mod files in there to install them.
Mods that require elevated privaleges, such as file access, will trigger a popup the next time the game is loaded before they are run.
**If a mod asks for this and you don't fully trust it, press “Quit” and uninstall the mod.**

## Other settings

- Use `--inspector` to launch the game with the web inspector and Javascript console enabled.
- Use `--menu` to launch the game with a chrome that allows opening the inspector, but does not do so by default.
- Use `--reset-trust` to revoke all permissions granted to privileged mods.

## Available Mods

The following is a list of all mods I am aware of:

### Debug Mode

[Download](https://f002.backblazeb2.com/file/publicdat/nnm/DebugMode.asar)

Enables the old DEBUGMODE setting, which starts you on a full save file.

### Classic Music

[Download](https://f002.backblazeb2.com/file/publicdat/nnm/ClassicMusic.asar)

Restores the old music from before the Steam version. Can be toggled in audio options.

### Any Character Any Quest

[Download](https://f002.backblazeb2.com/file/publicdat/nnm/AnyCharacterAnyQuest.asar)

Allows switching to any character in any quest. May cause crashes.
